AdaptML (Adaptive Markup Language) is a proposed modern markup language designed to build structured applications, websites, interfaces, and interactive experiences. It can have its own .adaptml files, Lexer, Parser, AST, Compiler, IR/SSA optimizer, Bytecode system, AdaptVM runtime, Standard Library, Module System, and Package Manager. Its goal is to provide a flexible, extensible language that can adapt to different application needs.
